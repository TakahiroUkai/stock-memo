最低購入代金クイズ

株価が1,500円で、1単元が100株の銘柄を買うときの最低購入代金はいくらでしょう?

解説

最低購入代金 = 株価 × 単元株数 = 1,500円 × 100株 = 15万円

初心者向けメモ

日本の株は、多くの銘柄で100株が最低の売買単位(単元株)です。そのため、株価だけを見て安いと思っても、買うときは株価の100倍のお金が必要です。

見るときのポイント

証券会社によっては、1株から買えるサービスもあります。ただし、配当の受け取りや議決権の扱いが違うことがあるため、事前に確認します。
