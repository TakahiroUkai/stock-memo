投資用語クイズ

投資指標の用語を、選択式のクイズで学べます。1問ごとに1ページで、回答すると初心者向けの解説が出ます。

第1問PER株価が1,000円、1株あたりの利益(EPS)が100円の会社のPER(株価収益率)は何倍でしょう?第2問PBR株価が800円、1株あたりの純資産(BPS)が1,000円の会社のPBR(株価純資産倍率)は何倍でしょう?第3問配当利回り株価が2,000円で、年間の配当が1株あたり60円の会社の配当利回りは何%でしょう?第4問配当利回りと株価年間の配当が60円のまま変わらず、株価が2,000円から1,500円に下がりました。配当利回りはどうなるでしょう?第5問ROE純利益が10億円、自己資本(会社が自由に使える自分のお金)が100億円の会社のROE(自己資本利益率)は何%でしょう?第6問配当性向純利益が10億円で、株主への配当の合計が4億円の会社の配当性向は何%でしょう?第7問自己資本比率総資産が200億円、自己資本が100億円の会社の自己資本比率は何%でしょう?第8問流動比率流動資産(1年以内に現金になる資産)が300億円、流動負債(1年以内に返す負債)が150億円の会社の流動比率は何%でしょう?第9問時価総額株価が500円で、発行済み株式数が2,000万株の会社の時価総額はいくらでしょう?第10問最低購入代金株価が1,500円で、1単元が100株の銘柄を買うときの最低購入代金はいくらでしょう?第11問営業利益率売上高が100億円で、営業利益が8億円の会社の営業利益率は何%でしょう?第12問EPS純利益が12億円、発行済み株式数が1,000万株の会社の、1株あたりの利益(EPS)はいくらでしょう?第13問PERの見方PERが低い銘柄について、正しい説明はどれでしょう?
